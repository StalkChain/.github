# StalkChain

StalkChain Data is a hosted crypto MCP server and REST API for research on public Solana and EVM wallets, token holders, and tracked-trader activity. Set up the connector in your AI client to check wallet holdings, compare trader PnL, or investigate who entered and exited a token.

| What you want to do | Where to start |
| --- | --- |
| Connect Claude, ChatGPT, Codex, Cursor, VS Code, or another MCP client | [Crypto MCP setup guides](https://github.com/StalkChain/fomo-mcp-api#install-and-research-guides) |
| Research wallets and token holders | [Solana wallet tracker MCP](https://github.com/StalkChain/fomo-mcp-api/blob/main/docs/guides/solana-wallet-tracker-mcp.md) · [Token holders and smart-money guide](https://github.com/StalkChain/fomo-mcp-api/blob/main/docs/guides/token-holders-smart-money-mcp.md) |
| Install StalkChain's research skills and workflows | [StalkChain plugin](https://github.com/StalkC/stalkchain-plugin) |
| Build a dashboard, alert, or research workflow against the REST API | [Developer documentation](https://stalkchain.com/docs) · [OpenAPI specification](https://data.stalkchain.com/api/v1/openapi.json) |

Use the [StalkChain connection page](https://stalkchain.com/mcp) to get started. The hosted MCP uses StalkChain OAuth, and metered lookups use account credits.

[Official MCP Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/com.stalkchain%2Fdata/versions/latest) · [StalkChain website](https://stalkchain.com/)
